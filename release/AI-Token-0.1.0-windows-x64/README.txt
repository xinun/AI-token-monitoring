AI Token 0.1.0 — Windows x64

1. ZIP을 원하는 폴더에 압축 해제합니다.
2. ai-token.exe를 실행합니다. 설치는 필요하지 않습니다.
3. 작업표시줄 오른쪽 AI Token 아이콘을 클릭하면 상세 창이 열립니다.
4. 설정에서 미니바에 표시할 AI를 선택합니다.
5. 종료하려면 트레이 아이콘 우클릭 → AI Token 종료를 선택합니다.

환경: Windows 10/11 x64, Microsoft Edge WebView2 Runtime.
WebView2가 없으면 Microsoft 공식 배포 페이지에서 설치합니다:
https://developer.microsoft.com/microsoft-edge/webview2/

Codex: 이 PC에 설치되고 로그인된 Codex CLI가 필요합니다.
Claude Code: 앱 설정의 '이 PC용 명령'으로 별도 연결합니다.
Antigravity·Grok: 아이콘 표시만 제공하며 한도 조회는 아직 지원하지 않습니다.

잔여값은 구독 한도의 퍼센트입니다. 실시간 스트리밍이 아니라
기본 5분 간격으로 조회하며, 앱 설정에서 조회 간격을 변경할 수 있습니다.

설정과 Claude 연결 스크립트는 해당 PC의 앱 데이터 폴더에 저장됩니다.
ZIP에는 계정 정보나 로그인 인증 정보를 포함하지 않습니다.

AI Token은 각 AI 서비스와 제휴하지 않은 독립 앱입니다.
서비스 아이콘 출처는 함께 제공되는 BRAND_ASSETS.md를 확인하세요.
